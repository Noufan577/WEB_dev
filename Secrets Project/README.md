# Secrets Project

This project is a small Express app focused on building a safe, simple login and secrets-sharing experience.

## Purpose

The goal of the project is to practice:
- working with Express routes
- handling user input and forms
- rendering pages with EJS
- managing authentication-style flows in a beginner-friendly project
- understanding how a basic web app handles user data

## Tech Stack
- Node.js
- Express.js
- EJS
- CSS
- Axios

## Features
- Submit and display secrets
- Manage a small web form workflow
- Practice real-world app structure and routing

## Run locally

```bash
npm install
node index.js
```

Then open:

```bash
http://localhost:3000
```

## Notes
This project is a beginner-friendly exercise in backend web development and helps connect front-end form interaction with server-side logic.
