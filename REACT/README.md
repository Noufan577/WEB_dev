# React Projects

This folder contains the React-based practice projects created during the course.

## Purpose

The goal of this section is to learn:
- React component structure
- rendering UI with JSX
- props and component composition
- state-driven interfaces
- front-end app building with Vite

## Included projects
- `my-react-app`
- `Emoji_desctriptor`
- `keeper-app-part-1-challenge`
- `todo_app`

## Tech Stack
- React
- Vite
- JavaScript
- CSS

## Run a project

Go into any project folder and install dependencies:

```bash
npm install
npm run dev
```

## Notes
This section represents the frontend part of the full-stack learning journey, where students move from server-side apps into modern React development and component-based UI design.
