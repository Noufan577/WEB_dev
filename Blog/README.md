# Blog Project

This project is a small Express + EJS blog-style app that demonstrates how to build a simple server-rendered website using Node.js and JavaScript.

## Purpose

The goal of this project is to practice:
- creating a Node.js server with Express
- rendering pages with EJS templates
- serving static files such as CSS
- handling basic form submissions and page flows

## Tech Stack
- Node.js
- Express.js
- EJS
- CSS
- Axios (used in related API-style versions of this course)

## What this app does
- Renders a blog homepage
- Shows a list of posts or content entries
- Uses server-side templates for page generation
- Helps practice front-end and back-end integration in a simple full-stack app

## Run locally

```bash
npm install
node index.js
```

Then open:

```bash
http://localhost:3000
```

## Notes
This project is part of the full-stack web development learning journey inspired by Angela Yu's course and is designed as a practical exercise in backend rendering and server-side web apps.
