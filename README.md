# Web Dev Learning Repository

This repository is a hands-on collection of projects and exercises built while following Angela Yu's full-stack web development course.

## Purpose

The main goal of this repo is to practice the full journey of modern web development, from basic front-end HTML/CSS/JavaScript to backend development, databases, and React.

It brings together small projects that cover:
- front-end fundamentals
- server-side development with Node.js and Express
- templating with EJS
- working with PostgreSQL databases
- CRUD operations
- React and component-based UI development
- real-world project workflows

## Project structure

This repo includes major project folders such as:
- Blog
- Family Travel Tracker
- Permalist Project
- Secrets Project
- REACT

These projects are practical implementations of course lessons and increasingly complex web development concepts.

## Learning path

The repository follows the typical progression of a full-stack course:
1. HTML, CSS, JavaScript basics
2. Node.js and Express backend development
3. EJS server-rendered web apps
4. PostgreSQL and database-driven projects
5. CRUD apps and data persistence
6. React front-end development
7. Building full-stack project thinking and app structure
